# D24: 日本語広告の新規クロール実行

## 目的
現在133件しかない品質広告を500件以上に増やす。日本市場の多様なジャンルをカバー。

## タスク

### 1. Meta Ad Library クロールスクリプト強化
- `backend/app/services/crawling/meta_crawler.py` を確認・改善
- 日本語広告専用のフィルタ設定
- ジャンル別検索キーワードリスト

### 2. バッチクロール実行スクリプト
- `backend/scripts/batch_crawl_japanese.py` を作成
- ジャンル別に以下のキーワードでクロール:
  - 健康食品: プロテイン, サプリメント, 青汁
  - 美容: 化粧品, 美容液, スキンケア
  - ダイエット: 痩せる, ダイエット, 脂肪
  - フィットネス: ジム, パーソナルトレーニング, 筋トレ
  - 金融: 投資, FX, 仮想通貨, 保険
  - EC: 通販, ショップ, セール
  - アプリ: アプリ, ゲーム, マッチング
  - 教育: 英会話, 資格, プログラミング
  - 不動産: マンション, 住宅, 引越し
  - 転職: 求人, 転職, 就職

### 3. クロール後の品質保証
- 自動スパムフィルタリング
- 自動ジャンル分類
- データベースへの品質データのみ格納

## 制約
- rankings.pyは編集禁止
- crawling/ と scripts/ のみ
