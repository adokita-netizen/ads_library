## タスク3: 動画URL抽出 (extract_missing_videos.py)

### 概要
video_url=NULLの88件に対して、Playwright でrender_adページをレンダリングし、
ネットワークインターセプト + DOM <video> 要素から動画URLを抽出。

### 注意事項
- Playwright の非同期処理を使用
- リクエスト間隔: 1.0秒
- Playwright待機: 8000ms
- ネットワーク応答をインターセプトして .mp4/.webm URLを捕捉
- **この処理は重い**（88件 × 8秒 ≈ 12分）ため、最終タスクとする

### 事前チェック
- `playwright` がインストールされているか確認
- print文のcp932チェック
- snapshot_url が存在するかの事前確認

### 実行
```bash
cd C:/Users/ishit/ads_library/backend && python scripts/extract_missing_videos.py
```

## 実行順序
1. backfill_media_urls.py（軽量、HTTP のみ）
2. fix_bad_thumbnails.py（中量、一部Playwright）
3. extract_missing_videos.py（重量、全件Playwright）

この順序で実行することで、先の軽量処理で解決した分は後の重い処理で省ける。
