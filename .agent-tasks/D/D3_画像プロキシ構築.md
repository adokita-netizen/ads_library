# Agent D タスク: 画像プロキシ＆ローカルキャッシュ

## 背景（最重要）
Facebook CDN URLが期限切れで45%がHTTP 403を返す。
thumbnail_s3_key/image_s3_key が全176件NULL。MinIOも未インストール。
→ フロントからサムネイルが一切表示されない致命的バグ。

## やること

### 1. 画像ダウンロード＆キャッシュスクリプト
`backend/scripts/download_media_cache.py` を新規作成。

- `backend/media_cache/thumbnails/` と `backend/media_cache/images/` ディレクトリを作成
- 全176件のthumbnail_urlとimage_urlをダウンロードしてローカル保存
- ファイル名: `{ad_id}.jpg` (シンプルに)
- ダウンロード失敗(403等)の場合はスキップしてログ出力
- 成功した場合、DBの `thumbnail_s3_key` を `media_cache/thumbnails/{ad_id}.jpg` に更新
- 同様に `image_s3_key` を `media_cache/images/{ad_id}.jpg` に更新
- flag_modified パターンでad_metadataに `media_cached: true` を記録
- リクエスト間隔0.3秒

### 2. 画像配信エンドポイント
`backend/app/api/endpoints/media.py` を新規作成。

```python
from fastapi import APIRouter, HTTPException
from fastapi.responses import FileResponse
import os

router = APIRouter(prefix="/media", tags=["media"])

CACHE_DIR = os.path.join(os.path.dirname(__file__), "..", "..", "..", "media_cache")

@router.get("/thumbnail/{ad_id}")
async def get_thumbnail(ad_id: int):
    path = os.path.join(CACHE_DIR, "thumbnails", f"{ad_id}.jpg")
    if not os.path.exists(path):
        raise HTTPException(404, "Thumbnail not cached")
    return FileResponse(path, media_type="image/jpeg")

@router.get("/image/{ad_id}")
async def get_image(ad_id: int):
    path = os.path.join(CACHE_DIR, "images", f"{ad_id}.jpg")
    if not os.path.exists(path):
        raise HTTPException(404, "Image not cached")
    return FileResponse(path, media_type="image/jpeg")
```

### 3. ルーター登録
`backend/app/main.py` にメディアルーターを追加:
```python
from app.api.endpoints import media
app.include_router(media.router, prefix=API_PREFIX)
```

### 4. スクリプト実行
作成後、ダウンロードスクリプトを実行して全画像をキャッシュする。
