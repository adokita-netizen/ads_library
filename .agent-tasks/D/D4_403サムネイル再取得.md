# Agent D タスク: 403サムネイルの再取得 & 動画サムネイル生成

## 背景
D3で176件中108件のサムネイルをキャッシュできたが、68件がHTTP 403（期限切れ）で取得失敗。
この68件のサムネイルを別の方法で補完する。

## やること

### 1. 代替ソースからのサムネイル取得スクリプト
`backend/scripts/recover_failed_thumbnails.py` を新規作成。

thumbnail_s3_key が NULL（= キャッシュ失敗）の広告に対して、以下の順番で代替取得：

**Phase 1: destination_url の og:image 取得（HTTP、高速）**
- destination_url にGETリクエスト → HTMLパース → og:image / twitter:image タグ取得
- 画像URLが見つかればダウンロードして `media_cache/thumbnails/{ad_id}.jpg` に保存
- thumbnail_s3_key を更新

**Phase 2: snapshot_url からのスクリーンショット（Playwright使用）**
- snapshot_url（Facebook広告ライブラリページ）をPlaywrightでレンダリング
- ページのスクリーンショットを撮影して保存
- Playwrightが使えない場合はスキップ

**Phase 3: 動画広告のフレーム抽出**
- video_url がある広告で thumbnail が取れていないもの
- video_url にHTTPリクエスト → 先頭数バイトだけダウンロード
- もしくはvideo_urlをそのままimage_urlの代替として使う（フロントのvideoタグでposter表示可能）

### 2. サムネイル品質の統一
全サムネイルを確認して：
- ファイルサイズが1KB未満 → 壊れているので削除、s3_keyをNULLに戻す
- 画像でない（HTML等がダウンロードされた場合）→ 削除、s3_keyをNULLに戻す

### 3. 結果レポート
最終的なキャッシュ率をprint出力：
- キャッシュ済み: X/176
- 未キャッシュ: Y/176 (理由: 403, LP無し, etc.)

## 制約
- INSTRUCTIONS.md のコンフリクト防止ルール厳守
- print文は英語のみ
- rankings.py, frontend/ は触らない
- media_cache/ ディレクトリに保存
- thumbnail_s3_key, image_s3_key の更新OK
- flag_modified パターン必須
- Playwrightが無い場合はPhase 2をスキップ
- リクエスト間隔0.5秒
