# Agent D タスク: クローリング改善 & メディア最適化

## 方向性
D1でメディアURL補完を行った。次はクローリングパイプライン自体の信頼性向上と、
メディアデータの品質を底上げする。

## やってほしいこと（優先順に）

### 1. メディア抽出ステータス管理
全広告の `media_extraction_status` を正確に設定するスクリプトを作る。
`backend/scripts/update_media_status.py` を新規作成。
- video_url + image_url + thumbnail_url が全て揃っている → "completed"
- 一部欠けている → "partial"
- 全てNULL → "pending"
- 以前の抽出でエラーが出た → "failed"
- ad_metadataに `media_extraction_status` と `media_completeness_score` を記録

### 2. クローラーのエラーハンドリング改善
`backend/app/services/crawling/` 内のクローラーを確認して：
- リトライロジックの確認・強化（3回リトライ、exponential backoff）
- タイムアウト設定の適正化
- エラー時のログ出力改善（どの広告で何が失敗したか追跡可能に）
- 改善点があれば修正する。問題なければ「確認済み、改善不要」と報告

### 3. creative_type 自動判定の精度向上
`backend/scripts/fix_creative_types.py` を新規作成。
- video_url があるのに creative_type が "image" のもの → "video" に修正
- image_s3_keys に複数画像があるもの → "carousel" に修正
- creative_type が NULL/unknown のもの → 利用可能なデータから推定
- 修正件数をサマリー出力
