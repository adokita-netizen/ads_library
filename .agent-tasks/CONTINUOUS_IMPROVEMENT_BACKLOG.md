# Continuous Improvement Backlog

最終更新: 2026-03-01

## 使い方
- このファイルは「どんどん良くする」ための継続改善タスク集。
- 毎スプリントで `P0` から最低1件、`P1` から最低2件を消化する。
- 完了したらタスク行末に ` [DONE: YYYY-MM-DD]` を付ける。
- 新規タスクは同じ形式で末尾に追加する（IDは連番）。

形式:
`CI-XXX | 優先度(P0/P1/P2) | 担当(A/B/C/D) | タスク | 完了条件`
