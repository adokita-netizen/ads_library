# C61: バックエンドテストカバレッジ向上

## 優先度: 🅱️ B（重要）

## 問題
- 30+テストファイルが存在するが、カバレッジ率が不明
- 主要APIエンドポイントの契約テストに漏れがある可能性
- 特にrankings.py（18,204行）の網羅が不十分

## 対象ファイル
- `backend/tests/` 配下全体
- `backend/app/api/endpoints/` の全エンドポイント

## タスク

### Task 1: カバレッジ計測
```bash
cd backend
pytest --cov=app --cov-report=html --cov-report=term-missing
```

### Task 2: 未テストエンドポイント特定
- 全APIエンドポイントのリスト作成
- テストファイルとの突合せ
- 未テストエンドポイントの優先度付け

### Task 3: 契約テスト追加（優先）
1. `rankings.py` の主要エンドポイント
   - `/rankings/pro-ranking` — 正常/ページネーション/フィルター/ソート
   - `/rankings/search` — キーワード検索/空結果
   - `/rankings/hit-analysis` — ジャンル別ヒット分析
2. `ads.py` — CRUD全操作
3. `media.py` — メディア取得/サムネイル/プロキシ

### Task 4: エッジケーステスト
- 空DB時の動作確認
- 不正パラメータ時の400エラー
- 存在しないIDの404エラー
- 大量データ時のページネーション
