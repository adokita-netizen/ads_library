# B54: Readable UI and Retry Operation Flow

## 目的
UIの情報密度を整理し、ジャンル別に見やすくしつつ、再抽出運用を迷わず実行できるようにする。

## タスク
1. UI整理（ごちゃつき解消）
- 主要情報を `検索 / フィルタ / 一覧 / 詳細` の4ブロックに再配置
- 不要要素（ストア系）を排除し、操作導線を最短化
- 一覧カラムは優先指標（媒体, ジャンル, 取得品質, 更新日）中心へ

2. ジャンルフィルタ強化
- `topic_label` と `matched_terms` で絞り込み
- クイックタグ（GLP-1, AGA, 脱毛, クレカ, 不動産 など）
- フィルタ適用時の件数・更新時刻を明示

3. 再抽出運用導線
- `needs_media_retry` バッジと一括再抽出ボタン
- 実行結果（成功/失敗/再試行待ち）をトースト + テーブル反映
- ブラウザ実機で「検索→再抽出→更新反映」E2Eを固定

## 完了条件
- [ ] 一覧と詳細が視認しやすい
- [ ] ジャンル別フィルタで探索が速い
- [ ] 再抽出の操作と結果反映をUIで確認できる
