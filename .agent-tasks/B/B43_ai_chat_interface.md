# B43: AI広告インテリジェンス・チャット

## 概要
Claude APIを活用した対話型AI分析インターフェースを構築する。
ユーザーが自然言語で広告データに質問でき、AIが分析結果・クリエイティブ提案を返す。

## 背景
VAAPは大量のデータと分析結果を持っているが、ユーザーが必要な情報にたどり着くまで
複数のビューを行き来する必要がある。
「美容ジャンルで最近伸びてる広告の共通点は？」のような自然言語クエリで
即座に答えが返る体験は、プロダクトの差別化要因として非常に強い。
