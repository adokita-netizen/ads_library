# B67: フロントエンド既知バグ修正（BUG-2,3,4）

## 優先度: 🅱️ B（重要）

## 問題
コードベースに既知のバグが3件タグ付けされている。

## バグ一覧

### BUG-2: ジャンル変更時に選択IDがクリアされない
- **場所**: ジャンルフィルター関連コンポーネント
- **症状**: ジャンルを切り替えても前のジャンルで選択したIDが残る
- **修正**: ジャンル変更のonChangeハンドラで`setSelectedIds([])`を呼ぶ

### BUG-3: winning pattern分析のメモ化不足
- **場所**: ヒット広告分析関連
- **症状**: 不要な再計算でパフォーマンス低下
- **修正**: `useMemo`でwinning pattern分析結果をメモ化

### BUG-4: mega_hitとhitカウントの分離
- **場所**: サマリ統計コンポーネント
- **症状**: mega_hitとhitが合算されて表示される
- **修正**: サマリ統計で`mega_hit`と`hit`を別カウントで表示

## 対象ファイル
- BUG-2: `grep -r "BUG-2" frontend/src/` で特定
- BUG-3: `grep -r "BUG-3" frontend/src/` で特定
- BUG-4: `grep -r "BUG-4" frontend/src/` で特定

## 完了条件
- [ ] BUG-2: ジャンル変更で選択状態がリセットされる
- [ ] BUG-3: useMemoで不要な再計算が抑制される
- [ ] BUG-4: mega_hit/hitが個別にカウント表示される
- [ ] 既存テストへの影響なし

## 制約
- 各バグは独立修正可能（順序依存なし）
