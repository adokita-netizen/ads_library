# Agent B: 分析ダッシュボード強化（フロントエンド）

## ミッション
ヒット広告を **視覚的に理解・比較** できるダッシュボードを構築する。
現状はテーブル表示のみで、「なぜこの広告がヒットしているのか」が直感的にわからない。
クリエイティブ比較、メトリクス推移、LP分析結果を一画面で確認できるようにする。

## プロジェクト情報
- パス: `C:\Users\ishit\ads_library`
- フロントエンド: `frontend/` (Next.js + React + TypeScript + Tailwind CSS)
- バックエンドAPI: `http://localhost:8000/api/v1`

### Phase 1: ヒット広告カード表示モードの追加

#### 1-1. HitAdCardView コンポーネント作成
**ファイル作成**: `frontend/src/components/dashboard/HitAdCardView.tsx`

現在のHitAdAnalysisView.tsxはテーブル表示のみ。
カードグリッド表示モードを追加して、クリエイティブを一覧で比較できるようにする。

```tsx
interface HitAdCardViewProps {
  ads: HitAd[];
  onAdSelect: (adId: number) => void;
}

// カード1枚の構成:
// ┌─────────────────────────────┐
// │ [クリエイティブ画像/動画]      │  ← CreativeViewer (縮小版)
// │                             │
// ├─────────────────────────────┤
// │ #1 HIT  商材名              │  ← ランク + HITバッジ + タイトル
// │ 広告主名                    │
// │ ──────────────────────────  │
// │ ヒットスコア ████████░░ 82  │  ← プログレスバー
// │ 推定消化額: ¥1,234,567     │
// │ 推定再生数: 1,543,200      │
// │ 配信日数: 45日 (配信中)     │  ← 生存状態の表示
// │ ──────────────────────────  │
// │ [LP確認]  [LP分析]  [詳細]  │  ← アクションボタン
// └─────────────────────────────┘
```

重要なポイント:
- `CreativeViewer` を縮小版（max-h-[200px]）で使用
- `destination_url` へのLP確認ボタン
- 配信日数 + 配信中/終了の状態表示
- ヒットスコアのプログレスバー（色分け: 80+赤, 50+黄, それ以下青）
- グリッドレイアウト: `grid-cols-1 md:grid-cols-2 xl:grid-cols-3`

### Phase 3: クリエイティブ比較機能

#### 3-1. 比較モードの追加
**ファイル作成**: `frontend/src/components/analysis/CreativeCompareView.tsx`

2-3件の広告を並べて比較できるビュー:

```tsx
interface CreativeCompareViewProps {
  adIds: number[];
  onClose: () => void;
}

// レイアウト:
// ┌──────────┬──────────┬──────────┐
// │ Ad #1    │ Ad #2    │ Ad #3    │
// │ [動画]   │ [画像]   │ [動画]   │
// │          │          │          │
// ├──────────┼──────────┼──────────┤
// │Score: 82 │Score: 71 │Score: 65 │
// │¥1.2M    │¥890K    │¥560K    │
// │45日配信  │30日配信  │12日配信  │
// │LP確認    │LP確認    │LP確認    │
// └──────────┴──────────┴──────────┘
```

使い方:
- HitAdAnalysisViewでチェックボックスで選択
- 「比較」ボタンクリックでCreativeCompareViewを表示

#### 3-2. HitAdAnalysisView にチェックボックス追加
```tsx
const [selectedIds, setSelectedIds] = useState<number[]>([]);
const [showCompare, setShowCompare] = useState(false);

// テーブルヘッダー最初のカラムにチェックボックス
<th className="w-8">
  <input type="checkbox" onChange={handleSelectAll} />

// 各行にチェックボックス
<td>
  <input

  </button>
)}
```

## 注意事項
- `next/image` は使わない（外部CDNドメインのホワイトリスト問題）→ 通常の `<img>` タグ
- `e.stopPropagation()` でチェックボックスクリック時に行クリックを防止
- react-hot-toast を使用してLP分析のフィードバック表示
- APIレスポンスは snake_case → フロントで camelCase 変換が必要な場合あり
- 既存のTailwindクラス命名規則に従う（text-[11px], card, badge-blue 等）
