# B31: PRO RANKING テーブル UX 大幅改善

## 目的
ProRankingView のテーブル表示を改善。リアルデータが133件あるので、それを活かしたUI強化。

## タスク

### 1. テーブルカラム最適化
- `frontend/src/components/dashboard/ProRankingView.tsx` を改善
- 表示カラム: ランク, サムネイル, タイトル, 広告主, ジャンル, ヒットスコア, 再生数, 期間
- タイトルは最大2行表示、ツールチップでフル表示
- ジャンルにバッジスタイル(色分け)を追加

### 2. フィルタリング強化
- ジャンル別フィルタ(15ジャンルのチップUI)
- スコア範囲スライダー
- 期間セレクタ(週次/月次/全期間)
- テキスト検索(タイトル/広告主名)

### 3. ソート機能
- 各カラムヘッダクリックでソート(ASC/DESC)
- デフォルト: ヒットスコア降順

### 4. ページネーション改善
- 現在のページ数表示
- ページサイズ切替(25/50/100)

## 制約
- `frontend/src/components/dashboard/` のみ編集
- fetchApiを使用(`@/lib/api`)
- Tailwind CSSのみ使用
