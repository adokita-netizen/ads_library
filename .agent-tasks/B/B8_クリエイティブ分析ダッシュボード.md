# Agent B タスク: クリエイティブ分析ダッシュボード

## 方向性
「なぜこの広告がヒットしているのか」をビジュアルで理解できるダッシュボードを作る。
動画広告分析のプロツールのコア画面。

## 利用可能なAPI（Agent C構築中）
```
GET /rankings/hit-factors          → フック/CTA/オファー/感情ごとのヒット率
GET /rankings/creative-dna/{ad_id} → 個別広告のクリエイティブ分析
GET /rankings/copy-analysis        → テキスト特徴の効果分析
GET /rankings/genre-winning-patterns?genre=X → ジャンル別勝ちパターン
GET /rankings/genre-comparison     → ジャンル別統計（既存）
GET /rankings/dashboard-summary    → KPIサマリー（既存）
```

## やること

### 1. ヒットパターン分析パネル（最優先）
HitAdAnalysisView.tsx に新しいタブ「分析」を追加するか、既存のサマリーエリアに組み込む。

**ヒット要因チャート**:
- `/rankings/hit-factors` から取得
- 横棒グラフで各要素のヒット率を表示
  - フック別（question, pain_point, benefit, ...）
  - CTA別（purchase, consultation, free_trial, ...）
  - オファー別（discount, free, limited_time, ...）
- 色分け: ヒット率70%以上=緑, 45-70%=黄, 45%以下=赤
- 「勝ちパターンTOP5」をカード表示

### 2. クリエイティブDNA表示
AdDetailModal.tsx に「クリエイティブ分析」セクション追加。

個別広告をクリックした時に表示:
- フック/CTA/オファー/感情のタグをカラフルなバッジで表示
- 「このパターンのヒット率: 75%」のような統計
- 同じパターンの他のヒット広告リンク
- テキスト特徴（絵文字あり、数字あり、体験談あり等）をアイコン表示

### 3. コピー分析パネル
テキストの書き方がヒットにどう影響するかを表示:
- 「数字を使う広告はヒット率75%」のような統計カード
- 「体験談系はヒット率82%」
- 「絵文字あり vs なし」の比較
- 平均文字数の比較（ヒット vs 非ヒット）

### 4. クリエイティブギャラリービュー
サムネイルをグリッド表示する新しいビューモード:
- 3-4列のグリッド
- 各カードにサムネイル画像 + スコアバッジ + フックタイプバッジ
- ヒット広告を先に表示（スコア降順）
- creative_type（動画/画像）のフィルター
- hook_type, offer_type でのフィルター
- カードクリックでAdDetailModal開く
