# B45: Crawl Reflection UI + Simplification Wave

## 概要
「クロール完了後に最新が見える」体験をUIで確実化し、画面のごちゃつきを解消する。
不要なStore系UIを除去し、ジャンル軸の見やすい導線へ整理する。

## 背景
- ユーザー体感では「完了表示なのに更新されない」問題が最重要
- フィルタ/導線が密集しており、操作負荷が高い
- Store関連UIは現状スコープ外でノイズになっている

## タスク

### Task 1: クロール成功後の状態同期UXを固定化
- クロール成功時:
  - 検索欄へ実行キーワードを自動反映
  - 一覧を即時再取得（invalidate + refetch）
  - 「何件追加されたか」を上部サマリに表示
- 反映遅延時の補助文言を追加（再取得中表示）

### Task 2: フィルタバー再設計（ジャンル中心）
- フィルタを3ブロック化
  - `検索`
  - `媒体 / ジャンル / 期間`
  - `ソート / 表示件数`
- ジャンルフィルタを視認しやすい位置へ固定
- モバイル時は折りたたみ可能にする

### Task 3: Store関連UIの撤去
- サイドバーやタブに残っているStore導線を削除
- 参照不能リンク・死んだUI状態を解消
- 既存機能に影響しないことを確認

### Task 4: クロール検索窓の回帰防止
- Enter送信、全角スペース、空入力バリデーションを固定
- Playwrightで以下を回帰テスト化
  - クロール実行→完了→一覧更新
  - キーワード自動反映
  - ジャンルフィルタ併用時の更新反映

## 完了条件
- [ ] クロール完了後に最新データが一覧に即反映される
- [ ] 画面密度が下がり、主要フィルタが1画面で把握できる
- [ ] Store関連UIが除去される
- [ ] E2Eでクロール検索導線の主要ケースが通る
