# B49: Knowledge Feedback UI + Dictionary Review

## 目的
蓄積ナレッジとAI辞書拡張をUIから継続運用できるようにする。

## タスク
1. クロール実行センターUI
- `定期実行状態` と `手動実行ボタン` を同画面に配置
- 実行結果（追加件数/失敗件数）を可視化

2. 辞書レビューUI
- AI提案語彙を `採用/保留/却下` で処理
- 採用時に対象カテゴリへ即反映

3. ナレッジ根拠ビュー
- 広告ごとの `topic_tags`, `evidence_terms`, `hit_drivers` を表示
- どの語が判定に効いたかを確認可能にする

4. ループ検証E2E
- 手動クロール→分類→辞書提案→採用→再分類 の一連をテスト

## 完了条件
- [ ] クロール運用状況をUIで監視できる
- [ ] AI辞書提案をUIでレビューできる
- [ ] ナレッジ根拠を広告単位で参照できる
