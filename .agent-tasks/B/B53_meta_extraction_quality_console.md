# B53: Meta Extraction Quality Console

## 目的
Meta広告ライブラリー粒度で「何が取れていて何が欠けているか」をUIで即判断できるようにする。

## タスク
1. 抽出品質コンソール
- ad_idごとに `画像/動画/本文` の取得状態を表示
- `quality_score` と `missing_fields` を可視化

2. 再抽出オペレーションUI
- 1件/一括で再抽出トリガー
- 結果（成功/失敗理由）を即時反映

3. 画質チェック表示
- 低解像度・サムネのみ・動画未取得をバッジ表示
- 詳細で証拠URLと抽出ソースを表示

4. E2E
- 取得状態表示
- 再抽出実行
- 結果反映

## 完了条件
- [ ] ad_id単位の抽出状態をUI確認できる
- [ ] 再抽出運用がUIで回る
- [ ] E2Eで回帰防止
