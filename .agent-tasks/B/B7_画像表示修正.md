# Agent B タスク: 画像表示の修正 & フォールバック強化

## 背景（最重要）
サムネイル画像が表示されない。原因はFacebook CDN URLが期限切れ(403)。
Agent Dがバックエンドに画像プロキシ(`/api/v1/media/thumbnail/{ad_id}`)を構築中。
Agent Cが `_resolve_thumbnail_url()` をプロキシURL返却に修正中。

フロントエンド側でも、画像表示のフォールバックとエラーハンドリングを強化する。

## やること

### 1. CreativeViewer の画像フォールバック強化
`frontend/src/components/common/CreativeViewer.tsx` を修正。

画像読み込み失敗時のフォールバックチェーン:
1. `imageUrl` (API返却値、プロキシURLまたはCDN URL)
2. `thumbnailUrl` (フォールバック)
3. `snapshotUrl` があれば「広告を確認」リンクを表示
4. プレースホルダー（広告タイプアイコン + 「画像を読み込めません」）

```tsx
// 画像ソースのフォールバックチェーン
const [currentSrc, setCurrentSrc] = useState(imageUrl || thumbnailUrl);
const [fallbackIndex, setFallbackIndex] = useState(0);

const fallbackSources = [imageUrl, thumbnailUrl].filter(Boolean);

const handleImageError = () => {
  if (fallbackIndex + 1 < fallbackSources.length) {
    setFallbackIndex(prev => prev + 1);
    setCurrentSrc(fallbackSources[fallbackIndex + 1]);
  } else {
    setImgError(true);
  }
};
```

### 2. HitAdAnalysisView テーブルのサムネイル列改善
テーブル内のサムネイル表示を改善：
- 読み込み中: 小さなスケルトンアニメーション
- 読み込み失敗: アイコン + creative_type表示（「動画」「画像」等）
- 読み込み成功: 現状どおりサムネイル表示
- `loading="lazy"` 属性追加で初期読み込み速度改善

### 3. AdDetailModal の画像表示改善
- CreativeViewerに同じフォールバック適用
- 動画URLがある場合はvideoタグで再生可能に（controls属性付き）
- poster属性にthumbnailUrl設定

### 4. 画像の遅延読み込み（パフォーマンス改善）
テーブル内の全画像に `loading="lazy"` を追加。
見えている行の画像のみロードし、スクロール時に残りをロード。
これにより初期描画速度が大幅改善。
