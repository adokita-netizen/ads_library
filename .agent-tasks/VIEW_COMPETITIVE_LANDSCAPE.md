# 競合プロダクト分析視点 — VAAP vs 既存ツール、勝ち筋は何か

## 主要競合

### 1. 動画広告分析プロ (douga-ads.com)
- **料金**: 月額 ¥30,000〜
- **データ量**: 数万件の動画広告DB
- **強み**: データ量、ヒットライン指標、業界標準
- **弱み**: AI分析なし、クリエイティブ生成なし、LP分析なし
- **対象**: 広告代理店、大手EC

### 2. Pathmatics / Sensor Tower
- **料金**: $500+/月
- **強み**: グローバル、マルチプラットフォーム、精緻なスペンド推定
- **弱み**: 日本市場弱い、日本語UI無し、クリエイティブ分析浅い
- **対象**: エンタープライズ

### 3. BigSpy / AdSpy
- **料金**: $149+/月
- **強み**: Facebook/Instagram 広告の大量DB、フィルター豊富
- **弱み**: 日本語広告は少ない、分析機能は基本的
- **対象**: アフィリエイター、D2C

### 4. Meta Ad Library (無料)
- **料金**: 無料
- **強み**: 公式データ、網羅的
- **弱み**: 分析機能ゼロ、UIが使いにくい、API制限厳しい
- **対象**: 誰でも

## VAAP だけが持つ武器（実装済みコードベース）

### 武器 1: AI クリエイティブ生成
- 競合: なし
- VAAP: OpenAI/Anthropic でコピー・スクリプト・ストーリーボード生成
- **状態**: コードあり、APIキー設定で即有効化
- **ユーザー価値**: 「ヒット広告を分析 → その場でコピー生成」ワンストップ

### 武器 2: Computer Vision による広告解析
- 競合: なし（人力分類のみ）
- VAAP: YOLOv8 物体検出、シーン検出、OCR、色分析、構図分析
- **状態**: コードあり、Worker デプロイで有効化
- **ユーザー価値**: 「どんなビジュアルがヒットするか」自動分析

### 武器 3: LP クロール＆分析
- 競合: 非常に限定的
- VAAP: Playwright でLPをスクレイピング、コンテンツ分析、比較
- **状態**: コードあり、Worker デプロイで有効化
- **ユーザー価値**: 「広告→LP→CVR」の全ファネル分析

### 武器 4: ヒット予測 ML
- 競合: なし（過去データのみ）
- VAAP: sklearn/XGBoost で「この広告はヒットするか？」を予測
- **状態**: コードあり、データ500件以上で有効化
- **ユーザー価値**: 出稿前にヒット確率が分かる

### 武器 5: パクりガイド（HOOK→BODY→CTA分解）
- 競合: なし
- VAAP: ヒット広告の構造を自動分解、クリエイティブブリーフ生成
- **状態**: フロントエンド実装済み
- **ユーザー価値**: 「この広告をどう参考にすればいいか」がすぐ分かる

## 競合に勝つための戦略

### 短期（1ヶ月）: データ量で追いつく
- 目標: 2000件のDB
- 方法: Meta API + マルチプラットフォームクロール
- これがないと「使えない」と判断される

### 中期（3ヶ月）: AI差別化で引き離す
- AI分析・生成機能を全面に
- 「分析 → 学習 → 生成」のワンストップ体験
- 競合が追いつくのに6ヶ月以上かかる

### 長期（6ヶ月）: プラットフォーム化
- テンプレートマーケットプレイス
- チーム機能
- API公開
- ロックイン効果
