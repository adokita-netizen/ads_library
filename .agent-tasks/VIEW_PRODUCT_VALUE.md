## MVP定義（最低限ここまで動かす）

### Must Have (リリースブロッカー)
1. **広告200件以上** — ジャンル毎に最低10件
2. **ランキング表示** — PRO DATABASE が機能する
3. **ヒット判定** — HIT/大HITバッジが正しく表示
4. **サムネイル表示** — 画像が壊れない
5. **検索** — キーワードで広告が見つかる
6. **詳細モーダル** — 広告の全情報が見える

### Should Have (1週間以内)
7. **CSVエクスポート** — データをダウンロードできる
8. **勝ちパターン分析** — ジャンル別のヒット要因が見える
9. **トレンド表示** — 急上昇広告が分かる
10. **LP遷移** — 広告のLPに飛べる

### Could Have (2週間以内)
11. **AI分析** — チャットで広告を分析
12. **クリエイティブ生成** — ヒット広告を参考にコピー生成
13. **広告比較** — 2-3件を並べて比較

### Won't Have (今のフェーズでは不要)
- チーム機能
- キャンペーン管理
- Meta広告連携
- ストア
- 通知/アラート

## 今日から1週間の価値創出ロードマップ

```
Day 1: データ整備（分類 + スコア計算 + サムネイル修復）
       → PRO DATABASE が「それっぽく」動く
       → 価値: 競合ツールの基本機能と同等

Day 2: 新規クロール100件追加
       → ジャンル毎にデータが揃う
       → 価値: フィルタリング・検索が意味を持つ

Day 3: メディア抽出（動画URL取得）
       → 動画プレビューが動く
       → 価値: 「動画広告分析」の名に恥じない

Day 4: 分析データ生成（クリエイティブDNA、勝ちパターン）
       → ヒット要因分析が表示される
       → 価値: 競合にない差別化機能

Day 5: UI検証・修正
       → 壊れた画面がない状態
       → 価値: デモ可能な品質

Day 6-7: AI機能有効化（APIキー設定）
       → AI分析・生成が動く
       → 価値: 最大の差別化ポイント
```
