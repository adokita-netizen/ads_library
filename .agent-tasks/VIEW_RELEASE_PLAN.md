# リリース計画視点 — v0.1 → v1.0 → v2.0 のロードマップ

---

## v0.1 — "動くデモ" (今週中)

### ゴール
投資家/関係者に「こういうプロダクトです」と見せられる状態。

### Must Deliver
- [ ] PRO DATABASE テーブルが200件以上の広告で動く
- [ ] サムネイルが80%以上表示される
- [ ] ヒット判定バッジが正しく表示される
- [ ] ジャンル別フィルタリングが動く
- [ ] 広告詳細モーダルが開く
- [ ] 壊れたビューが0（エラー表示 or 非表示）

### やらないこと
- AI生成機能
- Meta API連携
- チーム機能
- 通知/アラート

### デプロイ先
`https://d3qlbagx7gq5sp.cloudfront.net` — 既存の本番URL

---

## v0.5 — "使える MVP" (2週間後)

### ゴール
社内テスターが毎日使って「便利」と言える状態。

### 追加機能
- [ ] 検索が日本語で正しく動く
- [ ] CSVエクスポートが正常
- [ ] トレンド表示が機能する
- [ ] 勝ちパターン分析が表示される
- [ ] 広告比較機能が動く
- [ ] LP遷移が全広告で正確

### データ要件
- 500件以上の広告
- 5ジャンル以上にデータ分布
- 日次メトリクス(ad_metrics)が最低7日分

### インフラ要件
- Meta APIトークン有効
- 定期クロール(D7)稼働
- メディア抽出パイプライン稼働

---

## v1.0 — "有料で使える" (1ヶ月後)

### ゴール
外部ユーザーが月額課金で使いたいと思う品質。

### 追加機能
- [ ] AI広告コピー生成
- [ ] AI動画スクリプト生成
- [ ] LP分析・スコアリング
- [ ] 広告主プロフィール
- [ ] レポート生成（PDF/HTML）
- [ ] ブックマーク/コレクション
- [ ] 設定画面（APIキー管理）

### データ要件
- 2000件以上の広告
- 日次メトリクス30日分
- 動画URL取得率90%以上

### 品質要件
- API レスポンス p95 < 2秒
- ページ初期表示 < 3秒
- 稼働率 99%
- セキュリティ: CORS修正、APIキー暗号化、認証必須

### インフラ要件
- 自動クロールスケジューラー
- SQS batchItemFailures 対応
- Lambda requirements 軽量化
- DBインデックス追加

---

## v2.0 — "差別化" (3ヶ月後)

### ゴール
競合（動画広告分析プロ等）にない機能で差別化。

### 追加機能
- [ ] AI専門家チャット（広告分析アシスタント）
- [ ] シナリオビルダー（ヒット広告から学ぶ）
- [ ] 動画書き起こし + 感情分析
- [ ] 物体検出（クリエイティブ内の要素分析）
- [ ] ヒット予測ML（機械学習ベース）
- [ ] 類似広告検索（ベクトル埋め込み）
- [ ] 競合モニタリング（アラート機能）
- [ ] チーム機能（コメント、共有）

### データ要件
- 5000件以上の広告
- CV/NLP分析済みデータ
- ベクトル埋め込み計算済み

### インフラ要件
- ECS Worker のオートスケーリング
- ElastiCache (Redis) キャッシュ
- 場合によっては ElasticSearch
