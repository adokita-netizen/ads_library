## Journey 1: 初回訪問 — 「このツール何ができるの？」

- 期待: ダッシュボードが表示される

## 致命的な問題（推定）

| 問題 | 影響度 | 原因 |
|------|--------|------|
| サムネイルが全部壊れている | ★★★★★ | snapshot_urlのみ、403が多い |
| 数値がゼロだらけ | ★★★★★ | ad_metadataの分析フィールドが未埋め |
| 検索しても何も出ない | ★★★★☆ | 58件しかない |
| AI機能が動かない | ★★★☆☆ | OpenAI/Anthropic APIキー未設定 |
| Meta連携が動かない | ★★★☆☆ | Meta APIトークン無効 |
| ビューが白画面 | ★★★★★ | API 500エラーでクラッシュ |

---

## 最低限「デモできる」状態の定義

1. PRO DATABASE でランキングテーブルが表示される（サムネイル付き）
2. ジャンル選択でフィルタリングできる
3. 広告クリックで詳細モーダルが開く
4. ヒット広告分析でサマリーが見える
5. CSVエクスポートができる

この5つが動けば、プロダクトとして見せられる。
