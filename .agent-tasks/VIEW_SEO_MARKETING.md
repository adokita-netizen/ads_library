# SEO・マーケティング視点 — VAAPをどう売るか

## なぜプロダクトマーケティングの視点が必要か

- 良いプロダクトでもマーケティングなしでは使われない
- 競合との差別化ポイントを明確にしておく必要がある
- LP（ランディングページ）の設計にも影響する
- エージェントが機能開発する際の「誰のため?」の指針になる

## 競合分析

### 直接競合

```
BigSpy (海外):
  - 特徴: 大量の広告DB、多プラットフォーム対応
  - 弱点: 日本語対応弱い、UIが使いにくい
  - 価格: $99/月～

AdSpy (海外):
  - 特徴: Facebook/Instagram特化、強力なフィルター
  - 弱点: 日本市場に弱い、高い
  - 価格: $149/月

PowerAdSpy (海外):
  - 特徴: マルチプラットフォーム
  - 弱点: データ鮮度が低い
  - 価格: $49/月～
```

### 間接競合

```
Meta Ad Library (無料):
  - 特徴: 公式データ
  - 弱点: 分析機能なし、検索しかできない

SimilarWeb (大企業向け):
  - 特徴: トラフィック分析
  - 弱点: 広告クリエイティブ分析なし、高すぎる
```

### VAAPの差別化ポイント

```
1. 日本市場特化
   → 日本語の広告分析、日本語UI
   → 国内D2C/EC市場の知見

2. AIによるヒット予測
   → 単なるDB検索ではなく、AIが「ヒットする広告」を予測
   → 5シグナル自動分析

3. クリエイティブ分析
   → 動画の構成分析（フック、ボディ、CTA）
   → LP分析との連携
   → 音声書き起こし + 感情分析

4. 価格
   → 海外競合の1/3以下
   → 日本語サポート

5. カスタマイズ性
   → 自社に合ったスコアリング
   → コレクション/ブックマーク
```
