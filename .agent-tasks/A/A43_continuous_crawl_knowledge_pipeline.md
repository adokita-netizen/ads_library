# A43: Continuous Crawl + Knowledge Pipeline

## 目的
定期実行と手動実行の両方でクロールを回し、取得データを継続的にナレッジ化する。

## タスク
1. 定期クロール運用
- 日次/時間帯別ジョブを定義（朝昼夜）
- 失敗時リトライと実行ログ保存

2. 手動クロール即時反映
- 手動トリガー実行時の優先キュー投入
- 完了後の差分件数を記録

3. ナレッジ蓄積テーブル整備
- `topic`, `evidence_terms`, `hit_drivers`, `source_ad_ids`, `updated_at` を保存
- 日次で新規語彙と強い訴求語を集約

4. AI辞書拡張ジョブ
- 新規語彙候補をAIが提案
- 採用/保留/却下のレビュー履歴を保持

## 完了条件
- [ ] 定期/手動の両クロールが同一パイプラインで管理される
- [ ] ナレッジが日次で蓄積される
- [ ] AI辞書拡張の提案履歴が残る
