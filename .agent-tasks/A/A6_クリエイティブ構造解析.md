# Agent A タスク: クリエイティブ構造解析パイプライン

## 方向性
広告クリエイティブの「中身」を構造化データにする。
テキスト（タイトル・説明文）から、なぜヒットしているのかの要素を抽出・分類する。
これが広告分析プロツールの心臓部になる。

## やること

### 1. クリエイティブ要素抽出スクリプト
`backend/scripts/analyze_creative_elements.py` を新規作成。

全176件のtitleとdescriptionを分析して、以下をad_metadataの `creative_analysis` キーに記録：

```python
creative_analysis = {
    # フック分類（冒頭で何で注目を引くか）
    "hook_type": "question" | "statistic" | "pain_point" | "benefit" | "curiosity" | "social_proof" | "urgency" | "none",

    # CTA分類（行動喚起の種類）
    "cta_type": "purchase" | "signup" | "learn_more" | "free_trial" | "consultation" | "download" | "line_add" | "none",

    # オファー構造（何を提供しているか）
    "offer_type": "discount" | "free" | "trial" | "limited_time" | "bundle" | "comparison" | "none",
    "offer_detail": "初回80%OFF" | "無料カウンセリング" | None,  # 具体的なオファー文言

    # 感情訴求（どんな感情に訴えるか）
    "emotion": "fear" | "desire" | "trust" | "excitement" | "relief" | "curiosity" | "neutral",

    # コピー特徴
    "has_emoji": True/False,
    "has_numbers": True/False,  # 数字を使っているか（○○%、○○円等）
    "has_testimonial": True/False,  # 口コミ・体験談っぽいか
    "has_before_after": True/False,  # ビフォーアフター訴求か
    "text_length": "short" | "medium" | "long",  # description文字数
    "line_count": int,  # 行数

    # LP遷移先の種類
    "destination_type": "ec" | "lp" | "sns" | "app_store" | "corporate" | "other",
}
```

### 分類ロジック（ルールベース、AI不要）
- hook_type: descriptionの最初の1行を分析
  - 「？」で終わる → question
  - 数字+%や円 → statistic
  - ネガティブワード（悩み、つらい、困る等） → pain_point
  - ポジティブワード（簡単、楽、美しい等） → benefit
  - 「今だけ」「限定」「残り」 → urgency
  - 「○○万人」「話題」「人気」 → social_proof
- cta_type: 「購入」「申込」「無料」「LINE」「ダウンロード」等のキーワードマッチ
- offer_type: 「%OFF」「無料」「お試し」「限定」「セット」等
- emotion: フック+オファーの組み合わせから推定
- destination_type: destination_urlのドメインパターンから判定

### 2. ヒットパターン集計スクリプト
`backend/scripts/compute_hit_patterns.py` を新規作成。

creative_analysisの結果を集計して、ヒット広告 vs 非ヒット広告の傾向を分析：
- hook_type別のヒット率
- cta_type別のヒット率
- offer_type別の平均スコア
- emotion別のヒット率
- 「最強パターン」の特定（ヒット率が最も高い組み合わせ）

結果を `backend/exports/hit_pattern_report.json` に出力。
また、ad_metadataに `hit_pattern_rank` (このパターンの強さ順位) を記録。

## 制約
- INSTRUCTIONS.md のコンフリクト防止ルール厳守
- print文は英語のみ
- AIモデルは使わない（ルールベースのみ、高速で全件処理）
- ad_metadataキー: `creative_analysis`, `hit_pattern_rank`
- flag_modified パターン必須
