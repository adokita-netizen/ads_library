# A45: Full-Cycle Data Taskpack (Implement + Test + Fix)

## スコープ
データ基盤側で「実装→検証→修正」までを1タスクで完了させる。

## 実装
1. 低件数時の自動再収集ロジック
2. ナレッジ辞書更新パイプライン
3. 失敗レコード再処理キュー

## テスト
1. 単体: 再収集条件判定
2. 結合: クロール→保存→再分類
3. 回帰: GLP-1/AGA含む代表カテゴリサンプル

1. 失敗ケースをエラーコード別に自動再実行
2. 欠損フィールド補完不能時は隔離
3. 再発した不具合を週次で潰し込み
