# Agent A タスク: データ鮮度管理 & エクスポート機能

## 方向性
今のデータは「一度取って終わり」の状態。ユーザーが継続的に使えるように、
データの鮮度を保つ仕組みと、分析結果を外に持ち出せる機能が必要。

## やってほしいこと（優先順に）

### 1. 広告生存チェックの改善
`check_ad_survival.py` を強化して、まだ配信中の広告と停止した広告を正確に判定する。
- snapshot_url にHTTPリクエストして200かどうかで判定
- is_still_running フラグを更新
- last_checked_at 的なタイムスタンプをad_metadataに記録
- 結果サマリーをprint

### 2. CSVエクスポートスクリプト
`backend/scripts/export_ads_csv.py` を新規作成。
全広告データをCSVで出力できるようにする。
- 主要カラム: id, title, advertiser_name, hit_score, hit_level, days_running,
  estimated_spend, creative_type, destination_url, is_still_running
- score_breakdown の各シグナルも列にフラット展開
- 出力先: `backend/exports/ads_export_YYYYMMDD.csv`
- exportsディレクトリがなければ作る

### 3. データヘルスレポート
`backend/scripts/data_health_report.py` を新規作成。
DB内のデータ品質を一覧表示するスクリプト。
- NULL率（各カラムごと）
- creative_type分布
- hit_level分布
- 平均スコア、中央値
- 配信中/停止の割合
- 「このデータは使えるか？」が一目で分かるレポート

## 制約
- INSTRUCTIONS.md のコンフリクト防止ルール厳守
- print文は英語のみ
- 新規スクリプトは `backend/scripts/` に作成
- 既存スクリプトの構造（SyncSessionLocal使用、sys.path.insert等）に合わせる
